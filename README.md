# Snapflake Studio
A free 3D planner for six-arm snowflake building blocks. Everything runs in the
browser: designs are saved on each person's own device and nothing is sent to a server.

## Files
```
  index.html             the whole app
  manifest.webmanifest   lets phones install it to the home screen
  sw.js                  makes it work offline
  icons/                 app icons
```

To update the live app, upload the new files over the old ones.
